# Todo App

A beautiful and modern todo application built with React and Next.js.

## Features

- ✅ Add, complete, and delete tasks
- 🎨 Modern and responsive design
- 💾 Local storage persistence
- 🔍 Filter tasks (All, Active, Completed)
- 📊 Task counter
- 🧹 Clear completed tasks

## Getting Started

### Installation

1. Install dependencies:
```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the app.

### Build

Build the app for production:

```bash
npm run build
```

### Start Production Server

```bash
npm start
```

## Usage

1. **Add a task**: Type your task in the input field and click "Add Task" or press Enter
2. **Complete a task**: Click the checkbox next to a task
3. **Delete a task**: Click the × button on the right side of a task
4. **Filter tasks**: Use the All, Active, or Completed buttons
5. **Clear completed**: Click "Clear completed" to remove all completed tasks

## Technology Stack

- **React 18** - UI library
- **Next.js 14** - React framework with App Router
- **CSS3** - Modern styling with animations
- **Local Storage** - Client-side data persistence
